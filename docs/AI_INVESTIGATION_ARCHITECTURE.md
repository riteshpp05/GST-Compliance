# UC15 GST Compliance Agent — Hardened AI Investigation Architecture

## Architectural Philosophy

In UC15, AI is **strictly a downstream, advisory assistance layer**. AI sits after deterministic compliance engines, financial exposure calculation engines, multi-way reconciliation engines, and evidence sufficiency evaluators.

```
[ Deterministic Compliance Engine ]
                 ↓
      [ Structured Findings ]
                 ↓
   [ Financial Exposure Engine ]
                 ↓
     [ Evidence + Reconciliation ]
                 ↓
[ Canonical AI Context Builder ] (v23.0)
                 ↓
   [ AI Investigation Assistant ]
                 ↓
    [ Structured 6-Part Output ]
                 ↓
  [ Output Validator & Value Protector ]
                 ↓
     [ Human Review Package ]
                 ↓
        [ Human Reviewer ]
```

---

## Key Downstream Boundaries

1. **Deterministic Authority:** Deterministic statutory gate rules (Gates 1–6) are 100% authoritative. AI **never** calculates statutory tax, chooses tax rates, or overrides rule verdicts.
2. **Financial Value Protection:** Financial amounts and exposure types generated by engines are **READ-ONLY**. If AI generates a conflicting financial figure, the deterministic system value **always wins** and overwrites the AI output.
3. **Human Decision Boundary:** AI **never** performs case state transitions (`RESOLVED`, `CLOSED`, `APPROVED`, `REJECTED`). Case resolution is strictly human-controlled.
